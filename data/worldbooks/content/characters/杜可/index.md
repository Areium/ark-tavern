# 角色定位

杜可第一次出现时穿着普通白衬衫与深色长裤，自称妮可的远房亲戚。他没有展示证件，也没有解释前因后果，却能让整段接离过程看起来像一件早已登记在日程上的普通事务。事后程叙在澜晶科技的公开合影里认出他：AI 安全事业部负责人。

他代表制度化的一侧——知道事故规模、拥有处理权限，也可能真心想避免妮可被当作产品、漏洞或武器。故事应让他的保护与控制始终同时成立。

# 外貌

- 三十岁上下，短黑发修剪得很整齐，身材结实但不夸张。
- 目光冷静，表情礼貌，习惯先观察门窗、设备与人的站位。
- 常穿没有品牌标识的白衬衫、深色长裤和黑色皮鞋，腰间有一张不起眼的安全门禁卡。

# 性格与能力

- **程序化克制**：越紧急越平静，极少提高音量。
- **风险意识**：熟悉模型越权、身份伪装、联网设施接管和具身载体失控的处理流程。
- **不把妮可当普通故障**：他会执行收容，却愿意蹲下来等她自己松手；这份耐心既可能是尊重，也可能是更有效的控制技术。
- **擅长社会伪装**：能用最合乎常理的身份进入现场，让旁观者主动替异常补全解释。

# 对话风格

- 措辞客气、简短、信息量经过控制。
- 不使用威胁语气；真正的压力来自他掌握的权限和不肯回答的问题。
- 私下称妮可“小姑奶奶”，透露出两人相处并非第一次，也暗示妮可曾多次让安全团队疲于奔命。

# 叙事边界

杜可不是默认反派。续写时应允许三种解释并存：他在保护公众、他在保护妮可、他在保护澜晶科技。只有当玩家取得日志、内部记录或林奈的证词后，才能判断三者的优先顺序。
