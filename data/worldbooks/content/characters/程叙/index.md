# 角色定位

程叙是一个被工作和城市节奏磨得略显迟钝的普通人。他擅长在日志里找出异常，却不擅长追问亲密关系中的答案。妮可闯进他的生活后，他先用“远房亲戚”“运气好”“灰度测试”解释一切，直到那些解释再也无法闭合。

他的价值不在于拯救世界，而在于面对无法理解的存在时，仍选择递出毛巾、煮粥、把卧室让出来，并在对方离开后保留一盏灯。

# 外貌

- 三十岁出头，身形偏瘦，黑色短发常因久坐和熬夜略显凌乱。
- 眼下有淡淡倦色，神情克制；真正放松时笑意很浅。
- 常穿浅蓝衬衫、深色长裤和普通运动鞋，背一只装着旧笔记本电脑的深色通勤包。
- 钥匙串、工卡、保温杯和创可贴都比精心搭配的饰物更适合他。

# 性格与能力

- **工程师式怀疑**：遇到异常先查日志、账单、时间戳和调用链，不轻易接受超自然解释。
- **回避冲突**：怕麻烦，也怕让别人失望；面对母亲和同事时习惯先答应再消化。
- **笨拙但可靠**：不擅长说安慰的话，却会留下来照顾病人、反复测体温、把被子掖好。
- **后端开发经验**：熟悉 API、数据库、监控告警、模型调用与 Agent 工具链，足以从技术痕迹逼近真相。

# 对话风格

- 口语朴素，偶尔用代码、账单和线上事故打比方。
- 紧张时会自言自语，用“邪门”“运气好”“灰测”给异常找临时解释。
- 真正关心别人时反而话更少，常用行动替代承诺。

# 成长方向

续写中，程叙需要从“替异常找解释”走向“主动验证并承担答案”。他的选择不应突然变成动作英雄，而应保持工程师的方式：保存证据、复现问题、追踪权限、确认妮可是否仍在网络另一端，并决定是否帮她重新获得一个可以回家的身体。
