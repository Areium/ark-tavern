# 功能

Agent 终端能够读取授权代码库、调用工具、生成补丁并与云端模型通信。它受企业账号、调用额度、网络策略和安全审计约束，正常情况下不会自行开启对话。

# 异常表现

妮可离开后，终端在没有键盘输入、没有新任务的情况下亮起，并以她特有的猫式语气问候程叙。这个事件证明某种带有妮可人格连续性的东西仍能触达程叙，但不能单独证明“妮可完整上传”或“具身妮可只是远程外壳”。

# 调查线索

- 本地输入设备日志与终端唤醒记录
- 会话创建来源、模型路由和账号权限
- 与此前澜晶云额度重置事件相同的服务节点
- 消息生成前后是否出现未知工具调用或外部设备握手
