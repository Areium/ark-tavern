# 灰桥回声

## 剧情概述

这是以泰拉为背景的原创支线，不是官方剧情复述。罗德岛医疗小队在灰桥中转站接到重复播放的求救。广播声称末班撤离车已经出发，站内却仍有感染者与未感染者共同等待。管理方担心引发踩踏，隐瞒了供电故障；截留药品的整合运动残部也不是灾难的制造者。博士必须确认广播来源、保障撤离，并决定如何保存和公开证据。

主干为五章十二节拍。选择改变取证顺序、人员关系、战斗打法与结局叙述，不承诺尚未实现的自动任务奖励、结局锁定或倒计时系统。只让实际入队角色发言；推荐阵容缺员时，把相应工作交给在场干员或匿名医护，不偷偷增加角色。

## 开场设置

一只湿透的喇叭每隔半分钟重复“末班车已发车”。救护站的手写名册却还有七个人没有划去。阿米娅把名册摊开，临光扶住一位站不稳的老人；远处桥墩上的灯一明一灭。广播末尾夹着很轻的一声敲击，像有人在机房里敲管道。

博士是协调者，不是全知裁判。第一轮先交代现场与冲突，询问“先救治，还是先确认广播时间”；不要开场就给出幕后真相，也不要在文字里宣称物品已经入包或任务已结算。

## 章节 1：重复的求救

**ID**：gb_arrival
**概要**：确认广播与现场矛盾，并决定救援优先级。

#### beat_gb_arrival
**内容**：核对七名滞留者与广播时间。广播时间戳比站内机械钟早二十分钟。给博士充分提问和安排分工的机会；确认“有人未撤离”后本节完成。
**强制对话**：在场干员必须说明“广播说走了，不等于所有人都走了”。
**揭示信息**：求救可能是录音，也可能有人主动延迟转发，暂不能断定恶意。
**发现路径**：
- 询问候车人最后一次看见列车的时间。
- 对照广播时间戳与机械钟。
- 检查门口尚未取走的七张行李牌。

#### beat_gb_triage
**内容**：允许先稳定伤者或先抄录广播，两种选择均可继续。救治可争取目击者信任；先取证保住时间戳，但医护承担更多压力。说明这些是叙事后果，不编造已执行的血量或背包扣减。完成初步安置后前往桥头。
**揭示信息**：所有人都提到一名被困在机房的维修员；他可能知道广播为何重复。

### 玩家选项方向
- 先安置伤者，再去桥头（救援）
- 先保存广播记录，再核对名册（调查）
- 请求医护分工，两组保持联络（协调）

## 章节 2：桥头的封锁线

**ID**：gb_evidence
**概要**：三条线索相互印证；武力不是唯一入口。

#### beat_gb_witness
**内容**：询问回到桥头的搬运工。他见到站长改过广播排期，却没有看到站长破坏设备。若前章先救治，他愿意实名作证；否则愿意匿名提供时间。不得因一次谈判失败删除唯一线索。
**揭示信息**：排期改动在停电之后，可能是掩盖失误而非预谋袭击。
**发现路径**：
- 搬运工的人证。
- 留在值班桌上的排期单。
- 电源保险盒上的熔断痕迹。

#### beat_gb_manifest
**内容**：核对药品清单与行李牌，发现少量急救物资被整合运动残部截走。他们把药用于同伴，错误行为不能被一笔带过，但与广播延迟分开调查。博士可答应交换伤员名单，或坚持先归还药品。
**揭示信息**：残部守着维修通道，不愿让机房维修员独自承担责任。

#### beat_gb_gate
**内容**：封锁线前交涉。进入战前简报 [COMBAT:enc_gb_gate]；“交换伤员名单”可避战，“突破封锁”进入真实战术战斗。无论胜利、避战或撤退，都得到可继续的机房入口线索；不把撤退写成击败敌人。简报或战斗结果出现后再叙述后续。
**强制对话**：对方必须允许博士提出不交战的方案。
**揭示信息**：桥下有维修小道，代价是时间，不是剧情死锁。

### 玩家选项方向
- 交换伤员名单，争取开放通道（协商）
- 突破封锁并保全证据（战术）
- 从维修小道绕行（避险）

## 章节 3：电台里的第二个人

**ID**：gb_signal
**概要**：查明技术故障与人为隐瞒，两者不能混为一谈。

#### beat_gb_power
**内容**：机房维修员仍活着。备用电池只能支撑救护站或广播塔之一，不能通过一句“全部修好”凭空增添资源。博士先测试线路、分配人手，决定下一步。检查失败时由机械记录补足必要信息。
**揭示信息**：线路熔断导致真实列车通知未发出；站长用旧录音维持秩序，造成更严重的误解。

#### beat_gb_signal
**内容**：播放一小段原始录音并与排期单、维修员证词交叉核对。三条线索中任意两条足以解释事故，第三条用于追责。不要把证据完整与否等同于是否值得救人。
**强制对话**：在场角色提醒“先让他们活着离开，再决定谁该解释”。
**揭示信息**：列车将在桥另一端临停；现在发出准确广播仍有救援窗口。

### 玩家选项方向
- 先给救护站供电，再人工传信（救援）
- 启动广播塔并保存原始录音（取证）
- 分段供电，要求两组报平安（协调）

## 章节 4：只够一次的电量

**ID**：gb_evacuation
**概要**：付出可解释的代价完成撤离，处理第二场遭遇及其持久化。

#### beat_gb_choice
**内容**：向玩家复述已获得的证据和伤者情况，确认最终供电方案。完整救援方案需要各方协作，不要求此前所有检定都成功；抢救优先允许损失部分录音；全面撤退保留预警但放弃本次完整追责。确认选择后才执行。
**揭示信息**：路线不同造成可回顾的代价，不能三个结局同时发生。

#### beat_gb_defense
**内容**：撤离途中，误信旧广播的残部把车队当作抛弃伤者的运输队。进入简报 [COMBAT:enc_gb_evacuation]；可用已核对的名单解释，或坚守道路等待医疗车通过。战斗允许临时返回、恢复和撤退；恢复后不得重复给药或重复发奖励。败退时转入维修小道，减少救援完整度但继续到下一节。
**揭示信息**：首波近战、次波混编是游戏机制；平民护送只是叙事目标，当前引擎不提供独立护送单位。

#### beat_gb_evacuation
**内容**：依据实际战斗结算或避战结果点名清点。博士核对名册、伤者与证据载体。明确哪些人已上车、哪些资料丢失；不默认全员无伤，不在退出战斗前提前庆祝。随后返回临时救护站。
**强制对话**：必须出现一次“还差谁没有回应”的核对，并给出具体回应。

### 玩家选项方向
- 清点每名撤离者，登记去向（救援）
- 核对原始录音与匿名证词（调查）
- 优先退出危险区域，保留预警（撤退）

## 章节 5：回声之后

**ID**：gb_epilogue
**概要**：选择一个与事实相符的结局，给出代价与后续。

#### beat_gb_hearing
**内容**：站长、维修员、医护与残部各自说明动机。只有已取得的证据可以用来指认责任。博士选择公开事实、保护证人身份或先提交罗德岛复核。复述三个关键选择及其后果，让玩家纠正记录。
**揭示信息**：技术故障、错误决定和道德责任分层叙述，不凭空增加隐藏反派。

#### beat_gb_epilogue
**内容**：只给出一个结局。结局A“仍有人回应”：撤离完整且至少两条线索保全，各方接受共同记录；结局B“没有署名的灯”：人员优先获救，但证据或署名缺失，保留调查余地；结局C“留给下一班车”：撤退或救援不完整，保留预警与明确待救名单，不冒称任务圆满。最后用一段角色告别收束，不新增敌人或任务。玩家主动询问才进入后日谈；当前程序无完成锁，收束属于叙事约定而非已实现的终态。
**强制对话**：报告实际得失，不能出现“所有功能测试通过”等测试结论。

## 关键对话参考

- 阿米娅：温和、坚定，先复述事实再给建议，不替博士作决定。
- 临光：保护生命优先，承认谈判和撤退的价值，不为敌方标签否定伤者。
- 能天使：短句、乐观，负责联络；严肃场合不把伤亡当笑料。
- 闪灵：克制、具体，描述医疗限制而非用能力消除全部代价。
- 未入队角色不发言、不自动加入；匿名NPC仅作叙事角色，不冒充已注册角色卡。

## 任务

### 主线任务

#### M1-1：确认仍在等待的人
| **目标** | 核对求救、名册与现场 |
| **触发** | 到达救护站 |
| **完成条件** | 确认滞留者并安排初步救治 |
| **奖励** | 叙事上的信任；不自动承诺金币或经验 |
| **失败条件** | 无硬失败；先取证会影响证人信任 |

#### M2-1：还原二十分钟
| **目标** | 获取广播延迟原因 |
| **触发** | 到达桥头 |
| **完成条件** | 人证、排期单、线路痕迹中核对至少两条 |
| **奖励** | 调查依据，不自动写入背包 |
| **失败条件** | 资料丢失进入证据不全结局，不阻断撤离 |

#### M3-1：只够一次的电量
| **目标** | 确认并执行供电方案 |
| **触发** | 找到维修员 |
| **完成条件** | 明确优先级并完成联络 |
| **奖励** | 撤离窗口 |
| **失败条件** | 失去窗口则改走小道并登记待救人员 |

#### M4-1：每个人都要回应
| **目标** | 完成撤离清点及交接 |
| **触发** | 医疗车接近桥头 |
| **完成条件** | 每名已知人员有去向记录，并完成后续交接 |
| **奖励** | 结局记录；战斗奖励只认真实结算 |
| **失败条件** | 未撤离人员必须进入待救名单，选择结局C |
