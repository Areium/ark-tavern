# Arknights Tavern 使用教程

> 欢迎来到罗德岛！本教程带你从零开始玩转 Arknights Tavern —— 一款明日方舟主题的文字角色扮演游戏。跟着做不需要任何编程知识。
>
> 文中的截图用于帮你找到对应的按钮和界面；如果你打开的版本与截图略有差异，以你手上的版本为准。
>
> 本页也是游戏内「📘 文档」入口展示的内容。需要更完整的逐项说明，见仓库根目录 `README.md` 的「使用说明」一节。

---

## 一、这是什么

一款由电脑上的 AI 扮演「主持人」的文字游戏：你输入一句话、做一次选择，AI 就把故事讲下去。游戏内置：

- **剧情模式** — AI 自动推进故事线，你只需在关键时刻做选择
- **自由模式** — 和喜欢的角色自由聊天
- **战斗系统** — 剧情中遭遇敌人时，用卡牌在网格战场上指挥角色作战
- **世界书** — 为 AI 提供世界观设定的「背景资料库」，让剧情更贴合方舟世界

开始前需要准备：一台电脑，以及一个可用的 AI 模型服务（见「三、配置 AI 模型」）。

## 二、安装与启动

### 2.1 前置条件

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows / macOS / Linux |
| Python | 已安装并加入 `PATH`（开发记录使用 Python 3.12） |
| Node.js | 已安装（含 `npm`） |
| AI 模型 | 一个云端 API Key（OpenAI 兼容或 DeepSeek），或本地 [Ollama](https://ollama.com) |

> `chromadb` 用于向量记忆；未安装时向量记忆不可用，但不影响基础服务启动。

### 2.2 安装依赖（只需做一次）

```bash
# 后端依赖（在仓库根目录）
pip install -r requirements.txt

# 前端依赖
cd frontend && npm install
```

### 2.3 启动游戏

**方式 A：一键脚本（推荐）**

| 平台 | 命令 |
| --- | --- |
| Windows | 运行 `scripts\restart-win.bat`（或 `powershell -File scripts\restart-win.ps1`） |
| macOS | `bash scripts/restart-mac.sh` |

脚本会检查运行环境 → 结束遗留进程 → 启动后端 Flask → 等待就绪 → 启动前端并拉起游戏窗口。**关闭游戏窗口或按 `Ctrl+C` 即自动清理全部进程。**

> Windows 需先执行过 `cd frontend && npm install`；macOS 需仓库根目录存在 `.venv`。

**方式 B：手动启动两个服务**

打开两个终端窗口：

```bash
# 窗口 1 —— 后端 API 服务（默认 http://127.0.0.1:5000）
python src/app.py

# 窗口 2 —— 前端（Electron 桌面窗口）
cd frontend && npm run dev
```

### 2.4 桌面窗口还是浏览器？

- `npm run dev` —— 拉起 **Electron 桌面窗口**（默认方式）。
- `cd frontend && npm run dev:web` —— 只起浏览器版，然后**手动**打开 http://localhost:5173 。前端不会自动打开浏览器。

> 两个服务都要保持运行，关掉任意一个游戏都会停止。

## 三、配置 AI 模型

游戏需要连接一个 AI 模型才能讲故事。进入「⚙️ 设置」，在「LLM 配置」区域填写，然后点「测试连接」：

![设置页面](images/08-settings.jpg)

### 3.1 云端 AI（推荐）

1. 选择接口类型（自动 / OpenAI 兼容 / DeepSeek）
2. 填入服务商提供的 **API Key** 与**模型名称**
3. 点「测试连接」，显示可用即配置成功

### 3.2 本地 AI（Ollama）

1. 安装 [Ollama](https://ollama.com)
2. 在终端运行 `ollama pull qwen2.5:7b` 下载模型（名字可换成任意支持的模型）
3. 回到设置页选择「Ollama 本地」，填地址（默认 `http://localhost:11434`）与模型名称
4. 点「测试连接」验证

### 3.3 主备切换（可选）

同时配置云端与本地时，其中一个不可用会自动切换，对话不中断。

> 不配置也能进界面浏览内容，但对话会返回「LLM 后端不可用」。

## 四、界面导航

启动后进入**主菜单**，五个入口覆盖全部功能：

![主界面](images/01-main.jpg)

| 入口 | 图标 | 作用 |
| --- | --- | --- |
| 会话大厅 | 🏛️ | 游戏主菜单：管理所有存档，进入故事与战斗 |
| 角色 | 🎭 | 角色库、玩家身份、资产、卡牌 |
| 世界书 | 📖 | 世界书工作台：条目、Prompt 预览、节点图、会话条目 |
| 文档 | 📘 | 本教程 |
| 设置 | ⚙️ | 模型配置、外观、叙述选项 |

进入管理页后，顶栏提供同样这五项导航（外加「返回主菜单」）。**对话页与战斗页是全屏沉浸式页面**，没有侧栏——要改世界书绑定、阵容等设定，请先退出会话回到会话大厅。

底部状态栏（管理页）显示后端连接状态、AI 模型状态与版本号。

## 五、开始游戏

### 5.1 新建会话

「会话大厅」里的每个**会话**就是一份游戏存档。点「＋ 新建」向导按步走：

1. 选**模式**：剧情模式（体验完整故事线）或自由模式（和角色自由聊天）
2. 选**战斗模式**：`narrative` 或 `tactical` —— **创建后不可更改**
3. 可选：选剧情、绑定一本世界书、挑出场角色
4. 命名并创建，直接进入沉浸式对话页

创建过程是纯本地的，**不调用任何 LLM**；绑定世界书时会先给你看服务端真实解析出的候选范围。

### 5.2 剧情模式要点

- **做选择** — 叙述结束后点下方选项，或直接在输入框打字并回车
- **回退** — 每两轮之间点「↩ 回退」；展开回忆可「↩ 回退到此」；悬停自己的消息点 `✎` 修改后「保存并继续」
- **叙述变体** — 叙述右下角 `◂ 1/1 ▸` 切换版本；在最后一个版本再点 `▸` 可输入提示词重新生成
- **回忆** — 左侧面板底部是自动生成的章节摘要，可重新生成，间隔在设置页调整

### 5.3 自由模式要点

- 从「场景角色」/「场景物品」卡片点「+ 添加」把角色、物品放进场景
- 点角色旁的「对话」切换当前对话目标；多人在场时可发起群聊
- 点环境面板「编辑」选预设地点 / 天气 / 时间，或「✏️ 自定义...」输入任意值

### 5.4 世界书与战斗（简介）

- **世界书** — 支持导入酒馆世界书 JSON、角色卡内嵌世界书（PNG/JSON，自动连带导入角色）、聊天备份 `.jsonl`，也可粘贴 JSON；条目按关键词触发注入；可一键导出回酒馆 v1 格式。
  世界书按**用途**分两类，新建/导入时选择：
  - **剧情世界书** — 绑定到会话、可设为全局默认，条目会按触发词参与注入。
  - **资料库** — 存放大型 IP 世界书，**只供浏览与检索、不参与任何剧情**。在资料库里搜到合适的条目后点「加入剧情世界书」，选一本剧情书、按需要改一下标题/正文/触发词再提交即可；默认是原文照搬，来源书不会被改动。整条链路不需要配置模型，也不调用 AI。
  「世界书」页是一个带页签的工作台，四个页签分工固定：`条目`（条目列表、编辑、导入导出、资料库检索摘录）、`Prompt 预览`（这一轮**真正会插进模型提示词**的完整文本、顺序与插入位置，以及没进去的条目和原因）、`节点图`（按设定集选择剧情，在一张整页画布上编辑剧情节拍与战斗节点）、`会话条目`（按当前世界书的分类查看条目默认状态，并只列出绑定了这本书的会话；可把单个条目设为跟随默认、仅本会话启用或仅本会话停用）。会话特调不会改写世界书本身，也不会影响绑定同一本书的其它会话。「AI 自动构建依赖」已移除，依赖改由人手工维护；但旧「分类与载入」页签已撤销、其子视图当前未挂载，依赖配置的编辑 UI 处于未接线状态（`条目` 页上的配置保存条实际不可达，保留原路径待接线）。依赖数据、分类、载入规则、保存与撤销、范围预览的数据与接口都不受影响。
- **战斗** — 三种进入方式：对话页顶栏手动触发遭遇、会话大厅的「⚔ 战斗演练」、或无需会话的「战斗测试」。确认遭遇后先看**战前简报**并选打法（可谈判避战）；战斗中用数字键 `1-9`/`0` 或点击选牌，拖拽到目标格打出，`F` 结束回合，`Esc` 取消。战斗结果会回写到当前会话。

### 5.5 舞台模式与场景面板

- **记录 / 舞台**：对话页右上角可以在「记录」（完整消息流）和「舞台」之间切换。舞台像视觉小说：背景来自当前地点，
  场景角色的立绘站在台上，底部对话框逐句显示叙述与台词——点对话框（或空格 / 回车）推进，说话的角色会亮起来，
  走到末尾出现选项。想翻旧对话点右上角「记录」。
- **场景面板**：左侧图标栏是面板页签（角色 / 物品 / 环境 / 剧情 / 回忆 / 任务 / 数值 / 资源）。顶栏左侧的
  「收起面板」只留图标栏，点任一图标再展开。「资源」页可以给本会话换角色形象、上传战斗背景、导入导出存档。
- **数值**：先在「世界书」工作台给这本书定义统一的数值字段（例如体力、金钱、好感），角色页「数值」页签填角色的
  默认值，对话时在场景面板「数值」页改本会话的值；改动会随剧情回档一起回退，叙述时模型能看到这些数值。
- **给开发者**：场景面板是插件化的，把一个 `.tsx` 放进 `frontend/src/plugins/custom/` 就能加一页自己的面板，
  并通过 `ctx.stats` / `ctx.data` 读写系统数据。说明见 `frontend/src/plugins/README.md`。

## 六、设置一览

- **外观** — 三套皮肤（默认 / PRTS 全息终端 / 酒馆手札）与深色 / 浅色主题（皮肤激活时明暗由皮肤接管）
- **音频** — 背景音乐音量与音效音量
- **LLM** — 查看主备后端、切换端点、刷新列表、测试连接、叙述思考档位
- **剧情选项** — 自动生成选项、选项个数、回忆间隔、每轮目标字数上限、「选项填充到输入框」、角色对话以头像气泡展示

## 七、常见问题

**Q：界面提示后端离线 / 未连接？**
A：检查启动程序的终端窗口是否还开着，两个窗口都要保持运行。

**Q：对话没有回复？**
A：到「设置」里点「测试连接」，确认 AI 模型配置正确且可用。

**Q：怎么备份我的游戏进度？**
A：整个 `data` 文件夹就是你的游戏数据（会话、记忆、世界书等），拷贝它即可完成备份；也可以在会话大厅用导出 / 导入存档。

**Q：浏览器没有显示界面？**
A：前端不会自动打开浏览器。用 `npm run dev:web` 启动后，手动在地址栏输入 http://localhost:5173 。

**Q：卡片快捷键只有前几张有效？**
A：快捷键是 `1`–`9` 与 `0`，最多对应 10 张手牌。
