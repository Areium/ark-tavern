## 2026 年 10 月

### 2026-10-11 — 节点详情动画与精确轮次回档

会话节点详情只展示正文和回档操作，去掉创作指引、意图与重复摘要；展开/关闭使用滑入淡入动画，并遵循减少动态效果设置。历史作者卡按冻结演出帧的节拍身份关联，无可靠身份的记录保留独立运行节点卡片。

同一场景推进或复访覆盖最新状态前保存 checkpoint，回档提交运行时节点 ID 与可选 checkpoint ID，恢复对应轮次的正文、分支、树位置、演出和资源。同场景同轮次的新冻结状态替换旧回档点；过去已覆盖的状态无法追补。完整旧记录无需重建会话；缺资源快照仍可查看但不能回档，未来节点只读，历史与日志沿用截断语义。

提交：`0abfee7`。新增精确轮次 checkpoint 用例并更新节点图、回档锁与场景媒体检查。本文按提交与源码同步；本轮实际定向执行另行记录，不能由该条目推断真实用户存档、模型或原生 Electron 验收完成。

### 2026-10-11 — 剧情面板精简、只读节点详情与会话回档

剧情面板保留当前位置、默认展开的作者节拍骨架和角色状态，重复树列表与独立回忆面板移除。会话节点图支持双击或键盘打开只读详情，显示作者内容及运行节点正文、摘要、分支、轮次；有快照的历史节点可回档，作者内容不在此编辑。

历史节点按真实运行时 ID 与 `parent_id` 识别，不用推进后的参考节拍推断归属。回档期间按会话锁定续写、轮次回退、删消息和变体，并拒绝过期响应；回档修改会话进度，不写世界书。

独立回忆摘要的生成、重生成、提示词注入、间隔配置和 SSE 刷新链退休；`memories.json` 保留叙述历史、轮次与用量，旧摘要字段不再消费。节点摘要、剧情日志、角色向量记忆和偏离评估继续使用。

提交：`7344cea`。该提交新增或更新节点回档、图映射和无摘要流程用例；原提交记录合成 API 浏览器等检查，不证明真实模型或原生 Electron。本次同步文档的定向检查另行报告。
