# 卡牌网格战斗表现：第一轮验收（2026-09-27）

## 目标与范围

把一次行动整理成可读的「起手 → 命中反馈 → 扣血 → 死亡退场 → 结果」节奏。保留卡牌、回合、地形、数值和横版战斗规则。此次完成表现基础，不代表美术与音效已达到最终品质。

## 已完成

- 行动接口可选返回本次事件批次；前端顺序播放后才提交最终快照，避免目标先消失再播放攻击。
- HTTP 与 SSE 使用同一事件 ID 去重；SSE 会送完终局事件才结束连接。一次范围攻击只起手一次；旧接口的分批 SSE 也保留攻击分组。
- 播放期间锁定后续战斗操作；离开页面取消等待；过期状态请求不能覆盖正在播放的状态。
- Spine 和回退角色都有朝向、起手、受击、退场反馈；区分物理、法术、混合、暴击粒子与数字。血条带受伤拖尾；减少动态效果设置缩短位移与退场。
- 护盾累加、燃烧持续时间、净化的中间显示对齐引擎；每批结束由后端快照校正。
- 修复切换角色后可移动范围仍属于原角色的问题，并丢弃过期选中单位的 GET 响应。
- 日志显示抽牌和状态名称、正确移动坐标，隐藏原始事件 JSON；不再把卡牌原始伤害总和误报为实际扣血。

## 后续体验缺口

1. 窄屏需要重新安排队伍面板、网格与手牌，不能只缩小画面。
2. 当前动效是通用表现，尚无每张重点技能专属的镜头、声音层次和美术设计；音效调用已接通，但未进行主观听感验收。
3. 前端使用通用起手时长，不读取每个 Spine 的命中帧；特殊长动作仍需逐技能校准。
4. 状态持续时间在最终快照同步；回合衰减没有逐项独立演出。旧后端没有完整批次时仍仅能提供尽力播放，完整顺序保证要求前后端一起更新。
5. 浏览器验收覆盖独立演练，未完整游玩剧情分支或会话奖励确认；相关会话接口、续战与结算有自动测试覆盖。

下一轮建议先固定一场代表性战斗，完整试玩并收集体验问题，再选择 2–3 个重点技能做专属表现。避免在每次试玩中无限扩展改动范围。
