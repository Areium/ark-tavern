## 本轮交付

| 范围 | 当时完成的行为 |
|---|---|
| 播放顺序与事件传输 | 行动接口支持可选返回本次事件批次，前端播放后才采用最终快照，避免目标在攻击播放前消失。HTTP 与 SSE 按同一事件 ID 去重；SSE 送完终局事件才结束连接。一次范围攻击只起手一次，旧接口分批 SSE 也保留攻击分组。 |
| 操作与请求时序 | 播放期间锁定后续战斗操作；离开页面取消等待。过期状态请求不能覆盖正在播放的状态；切换角色后刷新可移动范围，并丢弃属于过期选中单位的 GET 响应。 |
| 角色与命中表现 | Spine 和回退角色均有朝向、起手、受击及退场反馈；粒子和数字区分物理、法术、混合伤害与暴击。血条带受伤拖尾；减少动态效果设置缩短位移与退场。 |
| 中间状态与最终校正 | 护盾累加、燃烧持续时间和净化的中间显示与引擎对齐；每批结束由后端快照校正。 |
| 战斗日志 | 显示抽牌、状态名称和正确的移动坐标，隐藏原始事件 JSON；不再将卡牌原始伤害总和误报为实际扣血。 |

审查发现的护盾投影、旧接口缓冲丢事件和跨批重复起手问题在本轮修复；跨批起手问题补有定向回归断言。这是本轮修复记录，不表示后来所有事件与技能均已覆盖。

### 浏览器演练与视口

本地浏览器演练「初遇整合运动」完成两波敌人，4 回合进入 `VICTORY`。实际操作包含范围法术、辅助增幅、移动和单体攻击，并触发暴击与未命中。观察到：

- 起手阶段保留旧血量，播放期间战斗操作禁用。
- 敌方移动、死亡退场、增援和胜利入口可用。
- 浏览器 error 日志为空；仍存在 Pixi/Spine 弃用警告。

1440×900 桌面视口检查通过。390×844 窄屏观察到既有三栏布局裁切，当时未完成移动端重排，不能称为窄屏验收通过。当前项目仅面向 PC，这一历史观察不构成当前手机适配待办；当时的单一桌面视口结果也不能替代现在规定的五组内容区尺寸及窗口模式验收。

## 当时未覆盖与体验缺口

以下保留本轮结束时的边界。除上节明确说明的 PC 定位外，本次整理未复验这些体验问题的当前状态。

| 范围 | 当时缺口或未覆盖项 |
|---|---|
| 专属技能表现与音效 | 仅有通用动效，尚无重点技能专属的镜头、声音层次和美术设计。音效调用已接通，但未做主观听感验收。 |
| 动画命中时机 | 使用通用起手时长，未读取各 Spine 的命中帧；特殊长动作仍需逐技能校准。 |
| 状态持续时间与事件完整性 | 持续时间在最终快照同步，回合衰减未逐项独立演出。旧后端不提供完整批次时只能尽力播放；完整顺序保证要求前后端一起更新。 |
| 剧情与会话流程 | 浏览器覆盖独立演练，未完整游玩剧情分支或确认会话奖励。相关会话接口、续战与结算有自动测试覆盖，但不能替代完整游玩。 |
| 当时的移动端观察 | 窄屏若要适配，需重排队伍面板、网格与手牌，不能仅缩小画面；当前 PC 范围按上节说明处理。 |

本轮提出的下一步建议是固定一场代表性战斗，完整试玩并收集问题，再挑选 2–3 个重点技能做专属表现。每次试玩应约定范围，避免不断扩展改动。该建议尚不构成已完成的下一轮验收记录。
