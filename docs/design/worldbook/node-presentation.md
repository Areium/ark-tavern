# 节点演出：背景与事件 CG

核对日期：2026-10-07。运行态以当前代码为准。

## 作者操作

在世界书「节点图」选择剧情入口、章节或节拍，打开「演出配置」。

- 「进入节点画面」在进入该节点时执行；未配置时保留当前画面。
- 「添加事件」支持进入节点、指定作者选项结算、条件由假变真。
- 图片从本书资源选择或上传。可选择背景/CG、铺满/完整显示、焦点位置、立绘显隐。
- CG 默认完整显示、隐藏立绘；背景默认铺满、显示立绘。新画面完整替换这些参数。
- 「应用到其他节点」一次替换多个目标的进入画面，保留目标事件，整批只记一次撤销。
- 保存之前可撤销。保存冲突保留草稿，不能覆盖其他窗口已经保存的版本。

所有画面都持续到下一条明确画面指令。没有按节点结束、轮数或秒数自动恢复的路径。
进入无配置节拍、推进对白、重新打开会话不重新应用上层背景。
进入明确配置了画面的章节/节拍会切换；即使图片相同，也执行该指令的展示参数。

## 当前数据契约

节点的 scene_media 仅使用 background / events；旧 background_url / cg_url / cg_title 已删除。

background 是一个画面：
- kind: image；asset: 本书相对路径。
- role: background / cg；fit: cover / contain。
- position: 两个 0–100 百分比；portraits: show / hide。

事件字段为 id、可选 title、trigger、可选 conditions、repeat、priority、actions。
trigger.kind 为 enter / choice / condition；choice_key 使用当前作者分支的 rule_key。
分支目录通过 GET /api/plot-graphs/<plot_id>/media-options?book_id=<book> 获取；
前端不自行计算规则哈希。修改分支规则后应重新选择绑定，失效绑定会阻止新会话创建。

条件复用 story_rules.validate_rules / evaluate_branch 的物品与数值口径，全部满足才执行。
暂未入阵容的角色条件不可满足。初始已经满足的 condition 事件不算假→真；
此时需要展示应配置「进入节点」事件并附加条件。
条件在会话创建、作者选择结算及每轮叙述落盘时采样；没有轮间瞬时边沿订阅器。

repeat 为 session / entry；entry 按实际配置节点计数，章节不随每个节拍重复。
重复节点引用的演出配置、全图重复事件 ID 都被拒绝。
同次触发先处理进入节点的画面（剧情→章节→节拍），再按 priority、事件 ID 排序执行事件；
较大 priority 后执行、覆盖前面的画面。

actions 当前只执行 set_visual，visual 使用上述画面结构。
数组和动作/资源种类判别字段保留未来同事件 BGM 与视频的扩展位置。
当前不开放音乐/视频控件，保存未实现动作或 video 类型会明确拒绝。
后续 BGM 应为独立通道，背景切换不隐含停音乐；
视频占用画面通道，结束行为、原声与 BGM 的关系需在实现播放器时定义。

## 图片归属与可携带性

asset_path 是实际书内路径，不是 API 分类名：
combat_backgrounds 的地址对应 combat/backgrounds；locations 对应 environment/Location。
资源列表和上传响应都返回 asset_path，前端必须核对资源 URL 的唯一 worldbook_id。
预览走 GET /api/worldbooks/<book_id>/presentation-image?asset=<path>，
服务器严格限制当前书、图片扩展、路径及符号链接。

新会话在剧情和世界书绑定完成后冻结演出配置，并复制使用图片到会话的
presentation-assets/<sha256>.<ext>。播放时只访问会话图片。
书籍的修改、重命名或删图不会改变已经冻结的会话画面。
会话目录导出包含这些文件；整书文件夹或 .arkwb 携带图配置和源图片。
存档保存图片文件引用，服务地址在读取时按当前会话 ID 生成；
导入产生新 ID 后仍访问导入副本，不指向原会话。
普通 SillyTavern JSON 保留扩展配置，但不包含外置图片的二进制数据。

## 会话、历史与回档

配置、触发收据、条件真值、节点进入次数、活跃画面均在 overlay.presentation。
每轮按叙述实际使用的节拍/章节记录演出帧；不能使用已经推进后的下一节拍。

作者选择的媒体动作与数值/物品/落点/选择凭据在同一次 overlay 原子替换中提交。
叙述失败时保留待完成选择，重试不再次触发。前端先保留最近可播放画面，
对应叙述及图片就绪后，从首句切图。图片失败继续显示上一可用背景并提供重试。

GET stage 是只读解析：round 查询读取冻结帧，不读取当前世界书或重新触发事件。
历史帧同时保存环境信息。节点快照保存演出运行态与该节点的完整帧；
回档后即使再次恢复保留的后续树节点，也不依赖已经裁剪的轮次索引。
已结算作者选项的会话要求节点回档，避免只剪文本而保留落点或待完成选择。

演出与叙述历史仍位于两个文件：各文件持久化不等于跨文件原子事务；
不承诺断电时的跨文件事务恢复。当前没有对旧会话或旧节点自动补建演出快照：
缺少完整历史帧或资源快照时明确拒绝历史读取/回档，使用新会话验收新配置。

## 彼岸双生示例

scripts/prepare_beyond_twin_presentation.py 从当前参考大纲和已有图片准备演出。
默认仅检查；--apply 先备份源 book.json、再次核对 SHA-256，再原子替换。
只改节点图条目，保留其他条目、大纲、数值字段、有效布局及自由备注。
过期节拍引用会被当前大纲替换，原图保留在完整备份中；工具重复运行结果不变。

示例包含 28 个节点、9 个 CG 事件：
- 章节使用房间、商场、餐厅、病中夜、办公区、工厂等已有背景。
- 相遇、商场、额度、林奈、高烧、杜可、离家、回声绑定对应 CG。
- 「先问清楚她是谁」触发倒地视角 CG。
- 电话节拍不配置画面，继续保留 CG；代码节拍明确切回房间背景。

## 验证与边界

- tests/test_scene_media.py：持续背景、文件冻结、选项原子提交/失败重试、
  条件边沿、按节点重复、缺阵容角色、历史、回档后重访、CAS、非法路径和扩展动作拒绝。
- tests/test_presentation_content.py：示例纯变换、幂等、有效布局及其他作者内容保留。
- 隔离真实 Flask/React 使用彼岸双生图片；叙述由显式离线脚本提供。
  浏览器实测批量保存、连续保存、上传、CG 背景/持续/替换、
  失败保留与重试、重入会话、节点回档和保留后续节点恢复。
- 五组 PC 内容区尺寸检查编辑器/舞台、滚动边界和主要操作；未要求手机验收。
- Electron 窗口/最大化/全屏切换及真实模型长流程需要另行验收，
  浏览器与构建结果不替代这两个门禁。
